# Python-Fundamentals-Capstone-Project---Survey-Feedback-Analyzer
Python-Assignment
This project is a Python-based Survey Feedback Analyzer developed as part of the Python Fundamentals module.

## Project Objectives

- Store survey feedback using a dictionary of lists
- Add new feedback dynamically
- Clean textual feedback
- Count feedback containing specific words
- Calculate average rating
- Find the longest feedback
- Identify unique words
- Sort feedback based on rating

## Technologies Used

- Python
- Jupyter Notebook

## Concepts Used

- Dictionary
- Lists
- Loops
- Conditional statements
- Functions
- String operations
- Sets
- `zip()`
- `sorted()`
